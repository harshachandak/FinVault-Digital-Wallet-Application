#FinVault – Digital Wallet Application

FinVault is a full-stack peer-to-peer virtual wallet that simulates a UPI-like payment system. It allows users to register, log in, and securely send money between accounts.

The project separates frontend and backend logic clearly, with the frontend built using HTML, CSS, and JavaScript (using OOP principles for UI structure) and the backend built using Node.js and Express.js.

It includes secure server-side validation such as PIN authentication, balance checks, and transaction safety rules. Data is stored using a simple JSON-based file system to simulate a database.

The application also features a responsive dashboard that shows real-time balance updates and transaction history.
